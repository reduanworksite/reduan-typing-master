বাংলা টাইপিং অনুশীলন

নিচের বাংলা অনুচ্ছেদটি টাইপ করুন। সঠিক অক্ষর সবুজ হবে, ভুল অক্ষর লাল হবে। প্রথম অক্ষর টাইপ করলেই টাইমার শুরু হবে।

দুটি কীবোর্ড মোড: Unicode মোডে আপনার নিজের সিস্টেমের বাংলা কীবোর্ড (যেমন Avro / Unicode) দিয়ে টাইপ করুন। Bijoy মোডে নিচের বিজয় কীবোর্ড দিয়ে টাইপ করুন — লাতিন কী চাপলেই সঠিক বাংলা অক্ষর আসবে (যেমন j → ক, d তারপর j → কি)। এই ওয়েবসাইট কোনো কীবোর্ড ইনস্টল করে না। Ctrl+V পেস্ট: ওয়েবসাইট, Word বা Google Docs থেকে কপি করা বাংলা লেখা Ctrl+V দিয়ে পেস্ট করা যায় — Unicode ও Bijoy দুই মোডেই। পেস্ট করা লেখা নিজে থেকে ঠিক হয়ে যায় (ভাঙা ড়/য় ইত্যাদি ঠিক হয়), তাই সঠিক লেখা সবুজ হবে।

বাংলা বর্ণমালা — Bangla Alphabet Reference

শিক্ষার্থীদের জন্য বর্ণমালার ছোট তালিকা। এটি শুধু দেখার জন্য — এখানে ক্লিক করলে টাইপ হবে না।

অআইঈউঊ ঋএঐওঔক খগঘঙচছ জঝঞটঠড ঢণতথদধ নপফবভম যরলশষস হড়ঢ়য়ৎং
Scoring rule: mistakes are counted per grapheme (যুক্তবর্ণ/কারসহ একটি অক্ষর = একটি একক) from the text that is on screen right now. If you press Backspace and fix a wrong grapheme, that mistake disappears from the count — it is not counted twice. WPM = (correct graphemes ÷ 5) ÷ minutes.
Bijoy কীভাবে টাইপ করবেন: j → ক, k → ত, d তারপর j → কি, c তারপর j → কে, c + j + f → কো, g → ্ (হসন্ত — যুক্তবর্ণ বানাতে), Shift+A → রেফ (র্)। পূর্ণ স্বরবর্ণ: g তারপর f → আ, g তারপর d → ই, g তারপর c → এ; অ = Shift+F, ও = x। বিস্তারিত ম্যাপ README-তে আছে।
