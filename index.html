Good to know

Honest scoring, no tricks

Your score is always calculated from the text that is on screen right now. If you press Backspace and fix a wrong letter, that mistake is removed from the count — it is not counted twice. See the README in the project repository for the exact rule.

Bangla typing works in two modes: Unicode (your own system Bangla keyboard, for example Avro) and Bijoy (a built-in Bijoy Bayanno keyboard — type j → ক, d then j → কি). There is also a SutonnyMJ display option for the Bangla passage. This site does not install or replace your keyboard.
